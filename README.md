# Fiuva Labs — Web Oficial (`fiuva.github.io`)

Sitio web oficial de **Fiuva Labs**, el estudio independiente y laboratorio digital de **Fiuva** (Investigador y Estudiante de Doctorado / PhD Student en la **UPNA**, Máster en Ingeniería Informática) dedicado al desarrollo de videojuegos, aplicaciones móviles e investigación en Inteligencia Artificial y Modelos Generativos de Imagen.
